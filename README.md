# AutoTune — Self-Optimizing Web Application

Complete full-stack implementation for the Nexus Tech Recruitment 2026 Problem 04.

The project demonstrates a continuous:

**MONITOR → PREDICT → OPTIMIZE → RECOVER**

### Metrics
CPU, memory, traffic, response time, database query time, active users and system load.

### ML
Random Forest classifier trained from a synthetic historical performance dataset generated by `backend/app/ml/train.py`.

### Optimization
The demo changes application-level state:
- enable response caching
- enable database query optimization
- reduce pagination limit
- disable heavy non-essential components

### Recovery
When the prediction returns to normal after the demo is reset, the standard application configuration is restored.

## Start backend

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Docs: http://127.0.0.1:8000/docs

## Start frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open: http://localhost:5173
